THIRD-PARTY SOFTWARE NOTICES AND INFORMATION

CodeBrix.Develop.Debug.LinuxX64 is a NuGet package that carries linux-x64
native binaries of the NetCoreDbg debugger. Everything in this package is a
build of third-party open-source software, as detailed below. The package
adds no original code beyond the packaging itself.

The CodeBrix.Develop.Debug repository additionally carries, under the android/
folder, a self-contained bundle for building the Android arm64 debugger pieces.
That bundle VENDORS pinned source subsets of third-party projects; see item 4.

If you have any questions about any third-party code referenced here, or if
you believe that any third-party code has been included in
CodeBrix.Develop.Debug.LinuxX64 in error, please open a new issue at:
https://github.com/ellisnet/CodeBrix.Develop.Debug/issues

4. Vendored source under android/ (Android arm64 debugging bundle)

   The android/ folder vendors small, pinned SOURCE subsets so the Android
   debugger pieces build with no network and no moving dependency. (It also
   carries prebuilt BINARIES: netcoredbg, libdbgshim.so and libtrace.so built
   from this repository, ManagedPart.dll built from src/managed/ -- all MIT,
   item 1 -- and the four Roslyn 2.3.0 assemblies covered by item 3 above.)
   Every
   vendored file retains its original per-file header
   ("Licensed to the .NET Foundation ... under the MIT license"). All of it is
   MIT, (c) Microsoft Corporation / .NET Foundation and Contributors; the MIT
   permission text is identical to the one reproduced under item 1 above.

   a. dbgshim source  ->  android/dbgshim/diagnostics-src/
      Project:  .NET diagnostics (dbgshim)
      Source:   https://github.com/dotnet/diagnostics
      Pinned:   commit 49690774d0221df76b01afafd6df730f406ae01b
      License:  MIT (https://github.com/dotnet/diagnostics/blob/main/LICENSE.TXT)

   b. CoreCLR headers / IDL  ->  android/netcoredbg/coreclr-deps/
      Project:  .NET runtime (CoreCLR), header/IDL subset + src/native/minipal
